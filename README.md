# Konnect Hub

Konnect Hub is Konnector LLC's own project delivery management platform: a board-based work tracker like Jira or Azure DevOps, rebuilt around how Konnector actually delivers.

## Naming

"Konnect Hub" is a working title. The product name must live in one config value (e.g. `APP_NAME`) and be read from there everywhere, so a rename is a one-line change.
